# Frontend API Reference

This page documents both the high-level TypeScript SDK (`@jetpack/client`) and the bundled `wasm-bindgen` bindings (`jetpack-wasm`, re-exported via `@jetpack/client/wasm`).

```bash
npm install @jetpack/client
```

## High-Level SDK: `JetPackAppClient<TOpcodes>` (`@jetpack/client`)

Source: `web/packages/jetpack-client/src/client.ts` and `types.ts`. By default, `JetPackAppClient` loads the bundled `@jetpack/client/wasm` module with zero configuration (`wasmModule`, `wasmModulePath`, and `wasmBinaryOrUrl` remain available as optional overrides).

Pass a `JetPackOpcodeMap` interface generated by [`jetpack codegen`](/publishing/cli-tools#jetpack-codegen---worker-path---out-path---strict) (`new JetPackAppClient<JetPackOpcodeMap>()`) for compile-time validation of opcodes, metadata shapes, required `Uint8Array` payloads, response types, and `onStream()` listeners. Omitting the generic (`new JetPackAppClient()`) falls back to `DefaultOpcodeMap` and stays 100% backwards-compatible.

### Methods

| Method | Signature | Description |
| :--- | :--- | :--- |
| `connectAndEnsureApp` | `(options: ConnectAndEnsureAppOptions) => Promise<this>` | Initializes WASM, connects & pairs if needed, pulls from `SignedAppCatalog` if absent, launches or attaches to the worker, mounts `JetPackControlBar`, and mounts/subscribes `JetPackLogTerminal` when `developer_mode === true`. |
| `ensureWorkerRunning` | `() => Promise<void>` | Ensures the sandboxed worker is running, relaunching it via `launch_app` if it was stopped externally (for example via Control Center or manual Stop). Concurrent callers share a single launch operation. |
| `stopApp` | `() => Promise<unknown>` | Terminates the active worker via `terminate_app(appId)`, rejects in-flight requests with `NOT_CONNECTED`, and sets `JetPackControlBar` status to `'Stopped'`. |
| `request` | `<K extends keyof TOpcodes & string>(opcode: K, ...args: OpcodeRequestArgs<TOpcodes, K>) => Promise<WorkerResponse<OpcodeResponseFor<TOpcodes, K>>>` | Sends a correlated `HybridFrame` (`target_worker = appId`) with zero-copy `Uint8Array` transfer and resolves with `{ opcode, payload, correlationId }`. Automatically wakes a stopped worker via `ensureWorkerRunning()` (and retries once on a no-active-worker `system.error` race) while respecting `timeoutMs`. |
| `onStream` | `<K extends (keyof TOpcodes & string) \| '*'>(opcode: K, callback: StreamCallback<K extends '*' ? string : K, OpcodeStreamPayloadFor<TOpcodes, K>>) => () => void` | Subscribes to unsolicited or streaming worker frames matching `opcode` (or `'*'`). Returns an idempotent unsubscribe function. |
| `onWorkerStopped` | `(callback: (event: AppWorkerStoppedEvent) => void) => () => void` | Subscribes to daemon `"app.worker.stopped"` events (`'idle_timeout'`, `'terminated'`, `'process_exited'`). Returns an idempotent unsubscribe function. |
| `onWorkerStarted` | `(callback: (event: { app_id: string }) => void) => () => void` | Subscribes to worker wake/relaunch events emitted after `ensureWorkerRunning()` succeeds. Returns an idempotent unsubscribe function. |
| `subscribeLogs` | `(onEntry: (entry: LogEntry) => void) => Promise<LogsSubscribeOkResponse>` | Subscribes to live sanitized daemon & worker `logs.entry` frames (`logs.subscribe`). Rejects with `DEV_MODE_REQUIRED` when Developer Mode is off. |
| `unsubscribeLogs` | `() => Promise<void>` | Unsubscribes from live log streaming (`logs.unsubscribe`). Safe to call repeatedly. |
| `isConnected` | `() => boolean` | Returns `true` when an authenticated session is active and bound to an ensured `appId`. |
| `isWorkerRunning` | `() => boolean` | Returns `true` when the session is connected and the app worker is currently active. |
| `getLastStopReason` | `() => WorkerStopReason \| null` | Returns the most recent `WorkerStopReason` (`'idle_timeout'`, `'terminated'`, `'process_exited'`) if stopped, or `null` while running. |
| `getAppId` | `() => string \| null` | Returns the currently ensured `appId`, or `null` if disconnected. |
| `getIdentity` | `() => WasmIdentityLike \| null` | Returns the active `WasmClientIdentity`, if initialized. |
| `getLastPairingUri` | `() => string \| null` | Returns the last generated `jetpack://pair?...` URI if auto-pairing ran. |
| `getRawClient` | `() => WasmClientLike \| null` | Exposes the underlying `JetPackWasmClient` for control-plane calls (`get_hardware_profile`, `reset_app_volumes`, etc.). |
| `getControlBar` | `() => JetPackControlBar \| null` | Returns the auto-mounted `JetPackControlBar` instance, or `null` when disabled (`controlBar: false`) or running headless. |
| `getLogTerminal` | `() => JetPackLogTerminal \| null` | Returns the auto-mounted Developer Mode `JetPackLogTerminal` instance, or `null` when Developer Mode is off, disabled (`logTerminal: false`), or running headless. |
| `close` | `() => void` | Closes the WebSocket, unsubscribes live log streams, clears stream/lifecycle listeners, rejects pending `request()` calls with `CLIENT_CLOSED`, hides `JetPackLogTerminal`, and marks `JetPackControlBar` as `'Stopped'`. |
| `destroy` | `() => void` | Calls `close()` and unmounts any auto-mounted `JetPackControlBar` and `JetPackLogTerminal`. |

### `ConnectAndEnsureAppOptions`

```typescript
export interface ConnectAndEnsureAppOptions {
  appId: string;
  daemonPort?: number;              // Default: 9470
  wsUrl?: string;                   // Overrides ws://127.0.0.1:<daemonPort>
  origin?: string;                  // Overrides window.location.origin
  ociReference?: string;            // Explicit OCI ref (for local/custom testing)
  autoPair?: boolean;               // Default: true
  resetVolumes?: boolean;           // Default: false
  pairingPollIntervalMs?: number;   // Default: 1500
  pairingTimeoutMs?: number;        // Default: 60000
  disableAutoDeepLink?: boolean;    // Default: false
  downloadUrl?: string;             // HTTPS download link surfaced on DAEMON_NOT_RUNNING
  healthProbeTimeoutMs?: number;    // /health pre-flight timeout in ms (default: 2000; 0 skips probe)
  fetchFn?: typeof fetch;           // Custom fetch implementation for /health probe (testing/SSR)
  onProgress?: (progress: AppPullProgress) => void;
  onPairingUri?: (uri: string) => void;
  wasmModule?: WasmBindingsAdapter;
  wasmModulePath?: string;
  wasmBinaryOrUrl?: unknown;
  controlBar?: boolean | JetPackControlBarOptions; // Default: auto-mounted in DOM
  logTerminal?: boolean | JetPackLogTerminalOptions; // Auto-mounted only if developer_mode === true
}
```

### `JetPackControlBar` & `JetPackControlBarOptions`

Source: `web/packages/jetpack-client/src/control-bar.ts`. Uses `attachShadow({ mode: 'open' })` for CSS isolation and safely no-ops in headless/SSR environments where `document` is undefined.

```typescript
export type ControlBarWorkerStatus = 'Connecting' | 'Running' | 'Stopped' | 'Error';
export type WorkerStopReason = 'idle_timeout' | 'terminated' | 'process_exited';

export interface AppWorkerStoppedEvent {
  app_id: string;
  job_id: string;
  reason: WorkerStopReason;
}

export interface JetPackControlBarOptions {
  appId?: string;
  appName?: string;
  controlCenterUrl?: string;           // Default: http://127.0.0.1:<daemonPort>/#apps
  downloadUrl?: string;                // Optional HTTPS download link for Error state
  logoUrl?: string;                    // Overrides built-in JetPack SVG icon
  mountTarget?: HTMLElement | null;    // Default: document.body; pass null to defer mount()
  initialStatus?: ControlBarWorkerStatus; // Default: 'Connecting'
  onBeforeStop?: () => Promise<boolean> | boolean;
  warnOnUnsavedWork?: boolean | (() => boolean);
  stopConfirmTitle?: string;
  stopConfirmMessage?: string;
  onStop?: () => Promise<unknown>;     // Wired automatically to client.stopApp()
  onRelaunch?: () => Promise<unknown>; // Wired automatically to client.ensureWorkerRunning()
  onAfterStop?: () => Promise<void> | void;
  onStopError?: (error: Error) => void;
}
```

| Method | Signature | Description |
| :--- | :--- | :--- |
| `mount` | `(target?: HTMLElement \| null) => boolean` | Inserts `#jetpack-control-bar-host` at the top of `target` (or `document.body`). Returns `false` if headless. |
| `unmount` | `() => void` | Removes the host element and clears modal/keyboard listeners. |
| `updateOptions` | `(partial: Partial<JetPackControlBarOptions>) => void` | Updates bar options live and refreshes rendered text/links. |
| `setStatus` | `(status: ControlBarWorkerStatus, detail?: string, options?: { downloadUrl?: string }) => void` | Updates the live status pill, optional `'Stopped'` status note or `'Error'` detail tooltip, and renders a sanitized `https://` `"Download JetPack"` link when in `'Error'` state (non-HTTPS URLs are ignored). |
| `getStatus` | `() => ControlBarWorkerStatus` | Returns the current status (`'Connecting'`, `'Running'`, `'Stopped'`, or `'Error'`). |
| `setAppName` / `setControlCenterUrl` | `(value: string) => void` | Updates the displayed app name or `"Control Center"` destination URL. |
| `triggerRelaunch` | `() => Promise<boolean>` | Invokes `onRelaunch()` when `status === 'Stopped'` and transitions the bar back to `'Running'` on success. |
| `triggerStop` | `() => Promise<boolean>` | Opens the Shadow-DOM confirmation modal when `warnOnUnsavedWork` evaluates to `true` or `onBeforeStop` is set (unless `warnOnUnsavedWork === false`); otherwise stops directly. |
| `confirmStopModal` / `cancelStopModal` | `() => Promise<boolean>` / `() => void` | Confirms (running `onBeforeStop` -> `onStop` -> `onAfterStop`) or dismisses the modal. |
| `isModalOpen` | `() => boolean` | Returns `true` when the stop confirmation modal is currently visible. |
| `getHostElement` / `getShadowRoot` | `() => HTMLElement \| null` / `() => ShadowRoot \| null` | Exposes the mounted host element and open `ShadowRoot`. |

### `JetPackLogTerminal` & Log Streaming Types

### `JetPackOpcodeMap`, `WorkerResponse` & `StreamCallback`

```typescript
export interface JetPackOpcodeEntry<
  TMeta = Record<string, unknown> | null,
  TResponse = unknown,
  TBinary extends boolean = boolean,
  TStream extends boolean = boolean,
> {
  meta: TMeta;
  response: TResponse;
  binary?: TBinary;
  stream?: TStream;
}

export type JetPackOpcodeMap = Record<string, JetPackOpcodeEntry<any, any, boolean, boolean>>;

export interface DefaultOpcodeMap {
  [opcode: string]: JetPackOpcodeEntry<Record<string, unknown> | null, unknown, boolean, boolean>;
}

export interface WorkerResponse<TResponse = unknown> {
  opcode: string;
  payload: Uint8Array;
  correlationId: number;
  readonly __responseType?: TResponse;
}

export interface StreamFrameContext<TOpcode extends string = string, TPayload = unknown> {
  opcode: TOpcode;
  correlationId: number | null;
  readonly __payloadType?: TPayload;
}

export type StreamCallback<TOpcode extends string = string, TPayload = unknown> = (
  payload: Uint8Array,
  context: StreamFrameContext<TOpcode, TPayload>
) => void;
```

### `JetPackClientError` & Codes

`JetPackClientError` exposes `readonly code: JetPackClientErrorCode` and `readonly downloadUrl?: string` (populated on `DAEMON_NOT_RUNNING`, defaulting to `DEFAULT_JETPACK_DOWNLOAD_URL = 'https://github.com/jetpack-desktop/releases/releases/latest'`).

| Code | Cause |
| :--- | :--- |
| `DAEMON_NOT_RUNNING` | `GET /health` timed out, failed to connect, or returned non-OK before pairing/WebSocket handshake. `err.downloadUrl` contains the sanitized `https://` JetPack installer link. |
| `NOT_CONNECTED` | `request()` or `stopApp()` called before `connectAndEnsureApp()` succeeded. |
| `CLIENT_CLOSED` | `request()` or `stopApp()` called after `close()`, or `close()` invoked while a request was in flight. |
| `PAIRING_TIMEOUT` | User did not approve `jetpack://pair` within `pairingTimeoutMs`. |
| `APP_NOT_IN_CATALOG` | `appId` is neither installed locally nor present in `SignedAppCatalog` (and `ociReference` was omitted). |
| `REQUEST_TIMEOUT` | Worker did not reply within `RequestOptions.timeoutMs`. |
| `WASM_LOAD_FAILED` | Failed to dynamically import `jetpack-wasm` bindings. |
| `INVALID_OPTIONS` | Missing or empty `appId` passed to `connectAndEnsureApp()`. |

## Low-Level WASM Bindings (`@jetpack/client/wasm` / `jetpack-wasm`)

Source: `crates/jetpack-wasm/src/identity.rs` and `client.rs` (bundled inside `@jetpack/client` under `@jetpack/client/wasm`).

```typescript
import initWasm, { WasmClientIdentity, JetPackWasmClient } from '@jetpack/client/wasm';

await initWasm();
```

### `WasmClientIdentity`

* `new WasmClientIdentity()` (`load_or_generate`): Loads or generates `client_id` (`UUIDv4`) + `Ed25519` / `X25519` 32-byte seeds in `localStorage` (`jetpack_client_id`, `jetpack_ed25519_seed`, `jetpack_x25519_seed`), falling back to ephemeral in-memory keys if storage is blocked.
* `WasmClientIdentity.generate_new_ephemeral()`: Creates a fresh in-memory identity without touching `localStorage`.
* `WasmClientIdentity.clear_storage()`: Removes persisted identity keys from `localStorage`.
* `identity.client_id`: Getter returning the `UUIDv4` string.
* `identity.public_key_bundle_base64()`: Returns the URL-safe Base64 64-byte (`Ed25519` + `X25519`) public key bundle.
* `identity.ed25519_pubkey_hex()` / `identity.x25519_pubkey_hex()`: Returns 32-byte hex public keys.
* `identity.generate_pairing_uri(origin)`: Validates and normalizes `origin` and returns `jetpack://pair?client_id=...&pubkey=...&origin=...`.

### `JetPackWasmClient`

| Method | Return Type | Description |
| :--- | :--- | :--- |
| `JetPackWasmClient.connect(wsUrl, identity, origin?)` | `Promise<JetPackWasmClient>` | Opens binary WebSocket (`arraybuffer`) and executes `ClientHello` / `ServerHello` handshake. |
| `is_connected()` | `boolean` | Returns `true` when in `Established` encrypted session state. |
| `get_hardware_profile()` | `Promise<HardwareProfile>` | Sends `hardware.get_profile` and resolves with CPU, RAM/unified memory, and GPU device details. |
| `get_catalog()` | `Promise<CatalogAppEntry[]>` | Fetches verified entries from the active `SignedAppCatalog` (refreshed via `catalog_url` with cached/embedded fallback), including `coming_soon?: boolean`, `launch_url?: string \| null`, and `poster_url?: string \| null`. |
| `list_apps()` | `Promise<AppInfo[]>` | Lists installed apps with `status`, `is_verified`, and sanitized `volumes` (`folder_name`, `is_configured`—never host paths). |
| `pull_app(imageRef, onProgress?, appId?)` | `Promise<AppPullOkResponse>` | Pulls a catalog-verified OCI app and streams `app.pull.progress` events (`percent` may be `number \| null`). |
| `launch_app(appId, resetVolumes?, onProgress?)` | `Promise<AppLaunchOkResponse>` | Starts sandboxed worker (`resetVolumes` forces fresh `rfd` folder prompts). Optional `onProgress` receives `app.launch.progress` events (`runtime_download`, `runtime_extract`, `uv_bootstrap`, `python_standalone`, `uv_sync`, `sandbox_launch`) while remaining compatible with 1- and 2-argument calls. |
| `reset_app_volumes(appId, volumeName?)` | `Promise<AppVolumesResetOkResponse>` | Clears persisted `authorized_volumes` entries in `paired_clients.db`. |
| `clear_app_cache(appId)` | `Promise<AppClearCacheOkResponse>` | Loopback Control-Center-only (`127.0.0.1` / `localhost`, rejecting non-Control-Center origins with `APP_MANAGEMENT_ORIGIN_FORBIDDEN` and active workers with `APP_IS_RUNNING`). Removes `<appdata_root>/<app_id>`, recreates an empty `0o700` directory on Unix, and clears `authorized_volumes` rows without touching mounted host folders or application bundles. |
| `uninstall_app(appId, removeCache?)` | `Promise<AppUninstallOkResponse>` | Loopback Control-Center-only (`APP_MANAGEMENT_ORIGIN_FORBIDDEN` / `APP_IS_RUNNING`). Removes all installed bundle directories for `appId` under `<apps_dir>`, and when `removeCache` is `true`, also removes `<appdata_root>/<app_id>` and clears `authorized_volumes` rows. Never deletes mounted host folders, `.core-apps-seeded`, shared blobs, or shared runtimes. |
| `terminate_app(appIdOrJobId)` | `Promise<AppTerminateOkResponse>` | Terminates a running job and its OS sandbox. |
| `list_paired_clients()` | `Promise<PairedClientSummary[]>` | Lists paired browser clients from `paired_clients.db`. |
| `revoke_client(clientId?, origin?)` | `Promise<ClientRevokeOkResponse>` | Revokes paired client access. |
| `get_settings()` / `set_developer_mode(enabled)` / `set_open_in_app_window(enabled)` / `set_open_dashboard_on_startup(enabled)` | `Promise<DaemonSettings>` | Reads or partially updates daemon UI settings (`developer_mode`, `open_in_app_window`, `open_dashboard_on_startup`, `daemon_version`, `appdata_dir`). |
| `pick_appdata_dir()` / `reset_appdata_dir()` | `Promise<DaemonSettings>` | Loopback-only (`127.0.0.1` / `localhost`). `pick_appdata_dir()` opens the daemon's main-thread OS folder picker (`rfd`) to choose a custom `appdata_dir` root (rejects with `APPDATA_PICKER_CANCELLED` on cancel); `reset_appdata_dir()` restores `<root>/appdata`. |
| `subscribe_logs(onEntryCallback)` | `Promise<LogsSubscribeOkResponse>` | Sends `logs.subscribe` and streams sanitized `logs.entry` (`{ timestamp_ms, level, source, message }`) frames; rejects with `DEV_MODE_REQUIRED` if Developer Mode is off. |
| `unsubscribe_logs()` | `Promise<LogsUnsubscribeOkResponse>` | Sends `logs.unsubscribe` and clears the active log callback. |
| `open_url(url)` | `Promise<UiOpenUrlOkResponse>` | Loopback-only caller (`127.0.0.1` / `localhost`). Opens either a validated loopback HTTP URL or an exact `launch_url` declared in the active Ed25519-verified `SignedAppCatalog` (with origin in `allowed_origins`) in a dedicated OS-native `wry` WebView window (`WKWebView` with `NSAllowsLocalNetworking` / `WebView2` / `WebKitGTK`, persisted under `<root>/webview-data` and intercepting `jetpack://pair` deep links) when `open_in_app_window` is `true` (with headless default-browser fallback) or a browser tab when `false`, resolving to `{ opened_in_app_window }`. |
| `export_diagnostics()` | `Promise<DiagnosticsExportResult>` | Requests `diagnostics.export` and returns `{ filename, generated_at_unix, log_tail_bytes, log_truncated, redactions_applied, zip_bytes }` where `zip_bytes` is a `Uint8Array` sliced from the binary frame. |
| `send_diagnostics()` | `Promise<DiagnosticsSendOkResponse>` | Requests `diagnostics.send` to transmit a sanitized diagnostic JSON report to `[diagnostics].report_url` (rejects with `[DIAGNOSTICS_DISABLED]` when `report_url` is unset). |
| `check_for_updates()` | `Promise<UpdateStatusResponse>` | Sends `update.check` and resolves with `{ current_version, latest_version, update_available, release_url, asset_name, checked_at_secs, error }`. |
| `apply_update(onProgress?, expectedVersion?)` | `Promise<UpdateRestartingResponse>` | Control-Center-only (`127.0.0.1` own origin). Sends `update.apply`, streams `UpdateProgressFrame` (`checking`, `downloading`, `verifying`, `extracting`, `installing`, `restarting`, `percent`, `bytes_downloaded`, `total_bytes`, `message`) to `onProgress`, and resolves with `{ target_version, restart_delay_ms }` before daemon restart. |
| `send_worker_frame(targetWorker, opcode, metaJs, rawPayload)` | `void` | Fire-and-forget encrypted `HybridFrame` dispatch to a worker. |
| `request_worker_frame(targetWorker, opcode, metaJs, rawPayload)` | `Promise<WorkerResponse>` | Correlated worker request matching `correlation_id`. |
| `on_worker_frame(callback)` | `void` | Registers `(opcode, payloadUint8Array, correlationId)` listener for unsolicited/stream frames. |
| `on_worker_stopped(callback)` | `void` | Registers `(event)` listener invoked when the daemon pushes `"app.worker.stopped"` (`{ app_id, job_id, reason }`). |
| `close()` | `void` | Closes WebSocket, clears log/worker listeners, and fails pending promises. |
